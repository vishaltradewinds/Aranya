# ARANYA Hardening Gate

ARANYA is not ready for real participant onboarding until these areas are tested:

- Core data model and lifecycle integrity
- Authentication and role-based access
- Producer, FPO, processor and buyer onboarding
- Produce and lot lifecycle
- Evidence and provenance
- Matching and order lifecycle
- Logistics and movement records
- Delivery and settlement records
- State-aware rule configuration
- Audit history
- Failure and recovery handling
- API and security controls
- Stakeholder dashboard permissions
- End-to-end automated tests
- Realistic transaction simulation

## Release rule

A feature is not complete because its UI renders.

It is complete when the relevant real-world workflow can execute, its records remain consistent, failures are recoverable, evidence is traceable, permissions are enforced, and the resulting transaction can be reconstructed from the audit trail.
