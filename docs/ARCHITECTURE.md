# ARANYA Architecture

## Common core

Identity → Organisation → Produce Registry → Lot → Evidence → Rules → Matching → Order → Movement → Processing → Delivery → Settlement → Audit

## Stakeholder views

- Producer / forest-dependent person
- Community / FPO / FPC / SHG
- Aggregator / collection centre
- Processor
- Buyer / industry
- Transporter
- Warehouse / depot
- Research / certification / NGO
- Authorised government users
- Platform administrator

Each view uses the same underlying records with role- and jurisdiction-based permissions.

## Regulatory approach

ARANYA records and operationalises applicable requirements; it does not independently exercise statutory authority. Central, state, product and transaction-specific requirements must remain configurable and versioned.

## First implementation focus

Madhya Pradesh, with a complete producer/community → aggregation → processor → buyer → movement → delivery → settlement journey before broader expansion.
